🚘 Welcome to the Number Plate Detection App

Detect and extract vehicle number plates using image uploads. Follow the guide below to get started:

📸

Start Prediction

Upload an image and get number plate results

📤 Step 1: Upload Image

Go to the Predict page and upload an image of a vehicle with a visible number plate.

🎯 Step 2: Detection

The system uses a fine-tuned YOLOv8 model to locate the number plate from the image.

🔠 Step 3: OCR & Result

Our OCR model reads the detected number plate and displays the alphanumeric value instantly.

💡 Quick Tips

  • Ensure the number plate is clearly visible and not blurry.
  • Upload images in JPG, JPEG, or PNG format.
  • For best results, use high-contrast images taken in good lighting.
